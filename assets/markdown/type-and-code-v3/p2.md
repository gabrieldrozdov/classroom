## ⚙️ {c:primary technical requirements}

::: columns

### 🔠 font

create a **variable dingbat pixel font** in glyphs with grid size `50`.

your font needs to contain the following glyphs:

- uppercase letters `A–Z`
- numerals `0–9`

*note: these glyphs should not be actual letters! instead, you should be designing pixel illustrations in place of each glyph.*

add **two variable axes** to your font with the following names:

1. Position `POSI`
2. Shape `SHAP`

add **three additional font masters** to your font and assign the following names/values to each font master:

1. `POSI=0, SHAP=0`
2. `POSI=100, SHAP=0`
3. `POSI=0, SHAP=100`
4. `POSI=100, SHAP=100`

+++

### 🌐 website

create an **animated ASCII art website** using your pixel font. your website should make use of each of the following CSS features at least once:

- `:hover` and `:active` states, combined with the `transition` property
- `@keyframes` animations
- `@media` queries, combined with the `transition` property

code your website either in [demoland](https://demoland.gdwithgd.com/editor/) or [visual studio code](https://code.visualstudio.com/).

publish your website via [github pages](https://docs.github.com/en/pages/quickstart).

*the use of ai is not permitted for this assignment and will result in automatic failure.*

:::
