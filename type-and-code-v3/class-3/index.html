variable pixel fonts 🏃

let’s learn how to turn a static font into a variable font. we’ll do this by drawing pixel self-portraits and then bringing them to life.

step 1

create a new pixel font. set up the pixel grid and draw a self-portrait in the uppercase letter A

step 2

add two variable axes to your font:

  1. 1
    Position POSI
  2. 2
    Shape SHAP

step 3

duplicate your first font master to add two additional font masters to your font and assign the following names/values to each font master:

  1. 1
    Normal, POSI=0, SHAP=0
  2. 2
    New Position, POSI=100, SHAP=0
  3. 3
    New Shape, POSI=0, SHAP=100

step 4

set your pixel grid back to 1.

now, we edit each font master!

  1. 1
    Normal → the default drawing
  2. 2
    New Position → change the pixel shape
  3. 3
    New Shape → move the pixels around

step 5

make one more font master by duplicating the New Position,POSI=100, SHAP=0 font master.

name this new font master New Shape and Position, POSI=100, SHAP=100

change the pixel shape in this font master to match the shape on the New Shape, POSI=0, SHAP=100 font master.

step 6

export your font as a variable font file and test it at font gauntlet↗!

variable component fonts ⭕️

this is an exercise/tutorial. we’re going to learn how to make component fonts by working with each other.

  1. 1
    we’ll design a few components.
  2. 2
    we’ll trade font files and draw illustrations in the ABCDE glyphs using the pre-made components.
  3. 3
    we’ll trade our fonts again and add a variable axis and modify the component shapes.
  4. 4
    we’ll keep trading our fonts, adding a new font master and a new component shape each time.
